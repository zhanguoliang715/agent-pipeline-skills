流水线 Skill 傻瓜式提示词模板
===============================

不会写提示词？直接复制下面任意一段，把【】里的内容换成你的话就能用。
模板分三档：跑整套、跑单棒、救场。每段后面跟的是这一棒的门禁脚本，
交稿前让你跑就跑（在工作区根目录）。

--------------------------------------------------
模板0｜跑整套（推荐，最省事）
--------------------------------------------------
【复制下面整段，把【】替换后发给任意一个 AI 助手】

走流水线，我要做【项目名】。想法：一句话说清楚【要做什么、给谁用、解决什么问题】。
按你的总调度流程从棒1到棒5走完整条流水线，产物用固定文件名 01-prd.md、
02-requirement-review.md、03-source\、04-qa-test-report.md、
05-security-pentest-report.md 放在当前工作区，每棒先跑对应门禁脚本再交稿，
打回就按路由重跑，最后给我五件套清单。

【交给总调度 pipeline-orchestrator 用。检查：走完整条流水线 + 确认工作目录】

--------------------------------------------------
模板1｜单棒：写需求（棒1 product-manager）
--------------------------------------------------
帮我写 PRD。项目是【项目名】，想法是【做什么、给谁用、解决什么问题】。
按你的 PRD 模板写完整十节，边界、验收标准、非目标写清楚。

【交稿前跑：python product-manager\scripts\check_prd.py 01-prd.md，
退出 0 才算过；退出 1/2 按提示补齐再交】

--------------------------------------------------
模板2｜单棒：审需求（棒2 requirement-reviewer）
--------------------------------------------------
帮我评审这份 PRD。文件：01-prd.md（如果不在当前目录，告诉我路径）。
按你的评审流程做六维度打分，给结论 YES / NO / 退回。

【交稿前跑：python requirement-reviewer\scripts\check_review.py 02-requirement-review.md，
退出 0 才算过；结论是退回就按路由打回棒1】

--------------------------------------------------
模板3｜单棒：写代码（棒3 software-developer）
--------------------------------------------------
帮我按这份已评审通过的需求写代码。评审结论文件：02-requirement-review.md
（结论不是 YES 就不要开工）。代码放 03-source\ 目录，配 README 说明怎么跑。

【交稿前跑：python software-developer\scripts\check_source.py 03-source\，
退出 0 才算过；检查清单里占位残留、混入依赖目录都要清】

--------------------------------------------------
模板4｜单棒：功能测试（棒4 qa-tester）
--------------------------------------------------
帮我测这份代码。源码目录：03-source\。按 README 搭环境跑主流程，
输出测试报告 04-qa-test-report.md，bug 按致命/严重/一般分级。
起不来就是致命 bug，直接打回开发。

【交稿前跑：python qa-tester\scripts\check_qa.py 04-qa-test-report.md，
退出 0 才算过；有未修复致命/严重项会退出 2】

--------------------------------------------------
模板5｜单棒：安全攻防（棒5 security-pentester）
--------------------------------------------------
帮我给这份代码做安全测试。源码目录：03-source\。
先确认授权（我自己的项目/已授权目标）再开打，输出报告
05-security-pentest-report.md，HIGH 必须修完再测。外部/公网目标直接拒绝。

【交稿前跑：python security-pentester\scripts\scan_security.py 03-source\，
退出 0 才干净；退出 1 有 HIGH 修完再扫】

--------------------------------------------------
模板6｜单棒独立部署（把某个棒单独拷出去用）
--------------------------------------------------
把【棒名，如 product-manager】整个目录拷到【目标位置，如 D:\my-work\pm\】，
以该目录为工作目录，我要【一句话需求】。按你的 SKILL.md 独立部署章节执行，
产物用固定文件名，交稿前在棒目录里跑对应脚本（命令见 SKILL.md 独立部署段）。

【提示词模板.txt 内的棒名、命令仅作示例，实际以对应棒 SKILL.md 独立部署章节为准】

--------------------------------------------------
打回了怎么办（救场）
--------------------------------------------------
评审说 NO / 退回   -> 把 02-requirement-review.md 的否决理由发给棒1，改完再审
测试有致命 bug     -> 把 04-qa-test-report.md 的致命项发给棒3，修完再测
安全有 HIGH        -> 把 05-security-pentest-report.md 的 HIGH 项发给棒3，修完再攻
（这些路由总调度会自动做，手跑时按上面三条人工接力）

--------------------------------------------------
最短提示词（什么都懂的人用）
--------------------------------------------------
走流水线做【项目名】：【一句话想法】
帮棒1写 PRD：【想法】
审这份需求：01-prd.md
按评审写代码：03-source\
测这份代码：03-source\
给这份代码做安全测试：03-source\

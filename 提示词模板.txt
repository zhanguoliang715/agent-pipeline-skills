流水线 Skill 傻瓜式提示词模板
================================
用法：复制对应模板，把【】里的内容改成你自己的，发给豆包就行。

==================================================
模板 0：从零跑完整条流水线（最常用）
==================================================
我要做一个软件项目，从零开始走完整条流水线，
由总调度（pipeline-orchestrator）统一编排：
产品经理 -> 需求审核 -> 程序开发 -> 程序测试 -> 安全测试。

我的项目想法是：【一句话说你想做什么，比如"一个待办清单网页，能加删改任务、标记完成"】
目标用户是：【谁用，比如"大学生自己用"】
技术偏好：【用什么，比如"Python + 网页"，不确定就写"你推荐"】
约束：【时间/预算/必须有的功能，没有就写"无"】

请你作为总调度，从第一棒开始，每完成一棒跑对应门禁脚本、
停下来告诉我结果，我确认后再进下一棒；被打回就按打回意见
自动路由重跑。最后把五件套（01-prd / 02-评审 / 03-source /
04-测试报告 / 05-安全报告）清单给我。

==================================================
模板 1：只写需求（product-manager）
==================================================
请你当产品经理，帮我写 PRD。

我想做的东西：【描述你的想法，越具体越好】
目标用户：【谁用】
必须有的功能：【列出来】
不要的功能：【列出来，没有就写"无"】

写完存成 01-prd.md，跑 check_prd.py 确认十节齐全、无占位再交给我。

==================================================
模板 2：只评需求（requirement-reviewer）
==================================================
请你当需求审核，评审当前目录下的 01-prd.md。

按六个维度打钩：边界清不清、能不能验收、有没有不做什么、
非功能需求写没写、里程碑明不明、有没有自相矛盾。

结论给 YES / NO / 退回。NO 或退回就写清楚打回清单。
写完存成 02-requirement-review.md，跑 check_review.py。

==================================================
模板 3：只写代码（software-developer）
==================================================
请你当程序员，按 02-requirement-review.md（结论应该是 YES）写代码。

代码放 03-source\ 目录，必须带 README.md 写清楚怎么启动、装什么依赖。
写完跑 check_source.py 确认 README 有启动命令、没有 node_modules/.venv 混进来。

==================================================
模板 4：只测功能（qa-tester）
==================================================
请你当测试，按 README.md 启动 03-source\ 里的程序，跑主流程。

把 bug 按 致命/严重/一般/轻微 分级，写进 04-qa-test-report.md。
起不来就记一条致命 bug 打回。写完跑 check_qa.py 确认没有未修复致命项。

==================================================
模板 5：只做安全测试（security-pentester）
==================================================
请你当安全工程师，对 03-source\ 做安全攻防测试。

注意：只测这个本地程序，不许打任何外部网站。
先跑 python security-pentester\scripts\scan_security.py 03-source\，
然后手动试 SQL 注入、命令注入、XSS、越权、路径穿越。

漏洞写进 05-security-pentest-report.md，按 严重/高/中/低 分级，
每个漏洞写清楚怎么复现。高危必须修完再测一轮。

==================================================
打回了怎么办
==================================================
如果某棒说 NO / 退回 / 打回，直接说：

  "根据打回意见改完了，重新提交，请重审。"

然后等下一棒重新跑。评审最多打回 2 次，到顶了你自己拍板。

==================================================
完整跑一遍的最短提示词
==================================================
直接发这句也行：

  "走流水线，我要做【一句话项目名】，想法是【一句话描述】。"

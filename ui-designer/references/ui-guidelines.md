# UI 设计规范要点（UI Designer）
> 配套 SKILL：ui-designer（具体版本见该 SKILL.md 的 version 字段，不在此写死）
> 本文件版本：1.0.0

## 设计系统
- [ ] 主色 / 辅色 / 强调色给出色值，并说明语义（主按钮/链接/错误/成功）
- [ ] 字体层级：标题/正文/辅助文字的字号与字重
- [ ] 间距与圆角有统一刻度
- [ ] 组件状态齐全：按钮（默认/悬停/禁用/加载）、输入框（正常/聚焦/错误/禁用）、弹窗/提示条

## 高保真图
- [ ] 每个原型页面都有对应设计图，命名=页面名
- [ ] 设计图内容密度接近真实（用真实文案/数据示例，不画空壳）
- [ ] 设计图与原型结构一致（不擅自增删页面）

## 开发可还原性
- [ ] design-spec.md 含色值表、字体层级、组件状态、每页对应 FR
- [ ] 交互状态（悬停/禁用/错误）在规范里有说明，前端不用猜

## 占位禁令
- [ ] design-spec.md 全文无 [待确认] / 【待补充】 / 非链接 < > 占位

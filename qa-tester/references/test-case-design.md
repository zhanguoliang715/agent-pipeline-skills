# 测试用例设计方法
> 配套 SKILL：qa-tester（具体版本见该 SKILL.md 的 version 字段，不在此写死）
> 本文件版本：1.0.1

## 每个 P0 功能至少覆盖四类

1. **正常流**：用户按预期操作，得到预期结果。
2. **边界值**：空值、0、最大值、最小值、刚好多一个字符/少一位。
3. **异常输入**：
   - 类型不对（要数字给字母）；
   - 超长字符串；
   - 特殊字符（引号、尖括号、换行、Emoji）；
   - 并发/重复提交（连点两下、刷新重试）。
4. **权限/状态**：未登录能不能访问、未满足前置条件能不能跳到下一步。

## 执行记录要求

- 每个用例记录：步骤 → 输入 → 预期 → 实际 → 通过/失败。
- 失败的用例必须配 BUG 单，BUG 单里写最小复现路径。
- 安全漏洞被开发修复后，本环节负责**功能回归**：除了复验该安全 bug，还要重跑受影响功能的旧用例，确认修漏洞没有改崩正常功能；回归通过后再交回安全环节复测。

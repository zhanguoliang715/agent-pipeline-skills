# Bug 严重程度分级
> 配套 SKILL：qa-tester（具体版本见该 SKILL.md 的 version 字段，不在此写死）
> 本文件版本：1.0.1

| 级别 | 定义 | 是否阻塞发布 |
|---|---|---|
| 致命 | 程序无法启动 / 主流程完全走不通 / 数据丢失或损坏 / 直接崩溃 | 是，必须打回 |
| 严重 | 某个 P0 功能不可用、结果错误、或在常见输入下崩溃 | 是，必须打回 |
| 一般 | 非 P0 功能有缺陷、UI 文案错误、边界小问题，有 workaround | 记录，可带风险放行 |
| 建议 | 体验优化、代码整洁、不影响功能 | 记录，不阻塞 |

> 判定口诀：一个普通用户想用它完成核心任务时，会不会被卡死？会卡 = 致命或严重；不卡但别扭 = 一般或建议。

> 用例怎么设计见 [test-case-design.md](test-case-design.md)，本文件只管 bug 分级。

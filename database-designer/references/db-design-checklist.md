# 数据库设计检查清单（Database Designer）
> 配套 SKILL：database-designer（具体版本见该 SKILL.md 的 version 字段，不在此写死）
> 本文件版本：1.0.0

## 表设计
- [ ] 每个 P0/MVP 的 FR 都找到数据落点（存哪张表）
- [ ] 表清单含：表名、用途、对应 FR、关联表
- [ ] 主键规则统一（自增 id 或业务主键，写明理由）

## 字段定义
- [ ] 每张表有字段明细：字段名、类型、主键、外键、可空、默认值、说明
- [ ] 关键字段有一句话业务含义，后端不用猜

## 关联关系
- [ ] 外键关系明确（users 1:N orders → orders.user_id）
- [ ] 多对多用关联表，且关联表字段定义完整
- [ ] 级联策略写明（删除主表时关联数据怎么办）

## 索引与约束
- [ ] 高频查询字段有索引
- [ ] 唯一约束/检查约束按业务规则加

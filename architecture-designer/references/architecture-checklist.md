# 架构设计检查清单（Architecture Designer）
> 配套 SKILL：architecture-designer（具体版本见该 SKILL.md 的 version 字段，不在此写死）

## 分层架构
- [ ] 分层清晰（表现层/接口层/业务逻辑层/数据访问层/基础设施层等）
- [ ] 每层职责一句话，层间依赖方向固定（上层依赖下层接口，禁止反向依赖）

## 模块划分
- [ ] 按业务领域/功能域拆模块，模块边界明确
- [ ] 模块只通过对外接口通信，不互相穿透

## 技术选型
- [ ] 按 PRD 非功能需求选型（性能/并发/部署形态），理由一句话写清楚

## 扩展性
- [ ] 明确"新功能往哪加"（新增模块挂哪、扩展接口定义在哪）
- [ ] 数据模型演进方式有说明

## 约束与约定
- [ ] 硬性规则写清：目录结构、命名、依赖方向，开发必须遵守

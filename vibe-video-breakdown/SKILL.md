# Vibe 知识演示视频：拆解与生成

处理 vibe 知识演示类短视频的两类任务。典型代表：抖音 #vibe知识大赏 频道的 AI 生成横屏知识片（深色电影感、诗意旁白、反直觉选题）。

- **模式 A · 拆解分析**：给链接/博主 → 采集数据 → 输出脚本/镜头/特效/声音拆解报告 + 播放量归因
- **模式 B · 脚本生成**：给选题 → 8 段式模板 → 输出可提交的分镜参数确认 → 路由 `doubao-creative-video` 继续制作

两类任务共用同一骨架，先读 `references/structure-template.md`，再按模式读对应参考。

## 模式 A：拆解一个视频/博主

### 1. 解析输入链接
- 抖音短链接 `v.douyin.com/xxx` 用 curl/Invoke-WebRequest 跟随重定向，解析出 `sec_uid`（用户主页）或 `aweme_id`（视频页）。
- 完整步骤见 `references/data-collection.md`。

### 2. 采集数据
按 `references/data-collection.md` 用浏览器自动化（`browser-use-automation`，`computer_use_tool` plane="bu"）采集：
- 主页：粉丝/获赞/作品数/合集/简介/置顶条
- 作品网格：滚动加载全部作品标题 + 点赞数
- 视频详情页：点赞/评论/收藏/转发、时长、合集集数、标签、发布时间
- 画面帧：定位 video 元素 → JS 设置 currentTime → screenshot 截帧（开场/标题卡/中段/高潮/结尾至少 5 帧）
- 完整旁白：用 `video_search` 按"博主名 + 标题关键词"搜索，snippet 取全文

### 3. 输出拆解报告
固定结构：
1. 博主画像（体量/定位/运营节奏）
2. 爆款数据表（点赞/评论/收藏/转发/时长/内核）
3. 逐段脚本拆解（时间轴表格：段落职责/画面元素/旁白要点）
4. 镜头与特效语言（画幅/转场/模型可视化/数据动效/字幕/氛围特效）
5. 声音设计（旁白腔调/语速/BGM）
6. 播放量归因（按 `references/selection-formula.md` 的归因清单逐项取证）
7. 可复制清单（用户能直接抄的动作）

归因不写空话：每条结论给画面/数据/文案证据。网页版不展示播放量时，以点赞为热度主指标并按 3-6% 点赞率估算播放量，明确标注"估算"。

## 模式 B：生成 8 段式脚本

### 1. 接收并校验选题
按 `references/selection-formula.md` 校验：是否命中"反直觉 × 大众生活话题"；有无收藏动机与点赞动机。不命中则提示调整，或直接给出符合公式的替代选题。

### 2. 套 8 段式模板
按 `references/structure-template.md` 逐段填充，每段写清：时间、画面元素、旁白逐字、镜头职责。时长按 2 分钟标准片缩放。

### 3. 输出分镜参数确认
- 参数列表 + 五列分镜表（时间/核心画面与动作/台词/运镜衔接/钩子与亮点）
- 台词用 `旁白：{逐字原文}` 格式，语速 2-4 字/秒
- 明确默认项：横屏 16:9、深色电影感、AI 旁白、vibe BGM、文献尾帧

### 4. 交接
实际视频生成路由 `doubao-creative-video` skill；本 skill 只负责拆解分析与脚本结构，不重复其生成流程。

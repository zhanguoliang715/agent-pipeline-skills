# 镜头与特效语言

## 画幅与基调

- 横屏 16:9 电影感（1024×576 或更高）。竖屏时代反着做，建立"纪录片"气质，与泛娱乐竖屏内容区隔。
- 深色底（夜空/墨色/星空）+ 粒子/流光氛围。
- 金色或高亮色标注关键信息（年代、人名、数字），其余画面低饱和。

## 转场语法

- 章节转场 = 金色年份卡：「1494 威尼斯·帕乔利」「1873 伦敦·高尔顿」——每次转场一个知识锚点。
- 卡间用光效/粒子过渡，不做生硬硬切。
- 章节卡本身承载信息（年代+人物+地点），不是纯装饰。

## 模型可视化（一题一模型）

每个知识点配一个能"动"的物理模型：

- 概率 → 骰子 / 坛中球 / 钉板 / 折线统计图
- 博弈 → 路网 / 弹簧 / 配对卡片 / 红线系定
- 心理/行为 → 进度条 / 大脑示意图 / 对比分屏

模型必须演示过程（车流汇聚、珠子堆积、红线系定、曲线生成），不是静态示意图。

## 数据动效

- 折线统计图实时生成、计数跳变、关键百分比放大标注。
- 每个数字写清变化路径与中间状态（如：第 2550 次抽样 0.600 → 真实比例 3/5）。
- 数值必须有来源，禁止编造。

## 画面内字幕

- 旁白逐字字幕，大字居中或下方，深色底金字/白字。
- 字幕与旁白完全逐字同步。

## 氛围特效

- 粒子、流光、慢速运镜、星空质感。
- 禁止闪屏、快切、炫技特效；节奏全程舒缓，特效服务情绪和信息，不抢信息。
